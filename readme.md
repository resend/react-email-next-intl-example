# React Email with next-intl

This example shows how to use [React Email](https://react.email/) with [next-intl](https://next-intl.dev/).

## Instructions

1. Install dependencies

  ```sh
npm install
  ```

2. Run Preview Server locally:

  ```sh
npm run dev
  ```

3. Open URL in the browser:

    http://localhost:3000
